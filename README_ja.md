## 利用手順

ゲーム、商品展示、アニメーション、3D 印刷などの用途を決めます。明瞭な参考画像や形状・材質の説明を用意し、生成後に全方向を確認。形状とテクスチャを修正し、書き出して使用先のソフトで検証します。

## 無料枠と納品条件

無料クレジット、プレビュー、試用期間は条件が異なります。モデル、出力形式、商用利用条件を確認してください。ビューアーの読込形式と生成結果の出力形式は別です。ゲームではトポロジーと UV、印刷では閉じた形状、肉厚、寸法を確認。画像は公開ページと公式デモであり、生成品質の比較実験ではありません。
