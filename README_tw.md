## 操作流程

先確定遊戲、商品展示、動畫或列印用途，再準備清晰參考圖或物體、形狀與材質描述。生成草模後檢查所有視角，修整幾何與貼圖，最後匯出並在目標軟體驗證。

## 免費範圍與交付

免費積分、預覽與試用各有範圍，須核對模型、下載格式與商用權益。查看器可讀格式不等於生成器可匯出格式。遊戲需檢查拓撲與 UV；列印需檢查水密性、壁厚與尺寸。截圖為公開頁面及官方示例，並非統一生成實測。
